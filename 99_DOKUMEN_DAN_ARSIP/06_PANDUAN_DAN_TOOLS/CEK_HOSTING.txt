Checklist provider hosting INPOS Node.js pada cPanel:

[ ] Menu Setup Node.js App (CloudLinux) atau Application Manager tersedia
[ ] Dapat memilih Node.js 22 atau lebih baru
[ ] Dapat menjalankan npm install, npx prisma generate, npm run build lewat Terminal/SSH
[ ] Terminal dapat menjalankan script seed admin sekali
[ ] MySQL tersedia; user memiliki izin CREATE/ALTER saat setup; versi DB sesuai Prisma
[ ] Resource limit memadai untuk NestJS/Prisma (RAM, CPU, proses)
[ ] Domain api.inpos.id dapat diarahkan ke root aplikasi Node.js melalui Passenger
[ ] Domain static inpos.id, app.inpos.id, adms.inpos.id, inpos.inpos.id bisa dibuat dengan root folder sendiri
[ ] AutoSSL aktif untuk 5 domain; HTTPS berjalan
[ ] Backup MySQL otomatis bisa diaktifkan
[ ] Hosting mengizinkan proses Node.js dan koneksi database tanpa dihentikan secara agresif

Jika salah satu prasyarat Node.js / Terminal / runtime gagal, gunakan VPS atau managed Node.js backend. Frontend dapat tetap di cPanel.

[ ] Untuk banyak toko: dukungan wildcard subdomain dan sertifikat SSL wildcard telah dikonfirmasi provider
