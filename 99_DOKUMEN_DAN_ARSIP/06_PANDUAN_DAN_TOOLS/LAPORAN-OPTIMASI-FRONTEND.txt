15 Oktober 2026

TARGET: inpos.id, app.inpos.id, adms.inpos.id, <slug>.inpos.id.
BACKEND: tetap, tanpa perubahan database.

PERUBAHAN:
1) Landing: stylesheet dan JavaScript inline dipindah ke /assets/*.hash.css/js.
2) Landing: 4 gambar inline (termasuk 2 gambar duplikat) diekstrak ke 3 file gambar cacheable; HTML berkurang tanpa mengubah foto/logo.
3) 3 frontend: script dan CSS di /assets/ dengan nama hash isi; HTML memakai path yang baru.
4) JavaScript defer; urutan client.js sebelum app.js/admin.js/store.js tetap terjaga.
5) .htaccess: Brotli jika tersedia, gzip fallback, cache immutable 1 tahun khusus berkas versi, HTML dan SW harus tervalidasi ulang.
6) PWA: cache shell v3, HTML network-first, aset versi cache-first, API tidak di-cache, ikon besar diunduh ketika diminta.
7) Kasir dan Web Toko: rendering produk bertahap (48 kartu). Daftar produk bertahap (60 baris), tetap mencari dari dataset penuh yang diterima.
8) Pengendalian race menu: hasil respons load navigasi lama tidak menimpa tampilan baru.
9) Sumber HTML/JS/CSS sebelum perubahan tersedia di folder 07_REFERENSI_JANGAN_UPLOAD, tidak untuk diunggah ke publik.

BATASAN:
- Belum ada tes beban produksi, hasil tidak menjamin cepat pada hosting shared atau database besar.
- Tidak ada modifikasi query backend, indeks database, atau paginasi API.
- Tidak ada minifikasi JavaScript esbuild karena dependensi tidak dapat diinstal di lingkungan build ini.
- Pastikan file .htaccess cocok dengan server (Apache; LiteSpeed biasanya mendukung sebagian besar perintah).
