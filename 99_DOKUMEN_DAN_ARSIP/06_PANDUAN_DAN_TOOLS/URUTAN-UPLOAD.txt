6. Setup Node.js App => root inpos-api; URL api.inpos.id/; startup app.js; Production.
7. Buat database MySQL + user dari cPanel, beri hak untuk init schema.
8. Copy .env.cpanel.example menjadi .env di inpos-api dan edit nilainya.
9. Aktifkan Node virtualenv dari petunjuk Setup Node.js App; jalankan npm install --include=dev, npx prisma generate, npm run build.
10. Jalankan npx prisma db push HANYA untuk database baru kosong, lalu npx tsx scripts/seed-initial.ts satu kali.
11. Jalankan npm run cpanel:check, restart aplikasi, tes https://api.inpos.id/v1/health.
12. Tes login Super Admin & Owner, QRIS, stok, penjualan, dan Web Toko.
